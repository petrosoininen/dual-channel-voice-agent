# Glossary

- **Acknowledgment:** short voice output describing understood intent and next process
  step; never a finding.
- **Deep work:** serialized agent operation that may propose a document change.
- **Canonical document:** backend-owned current structured analysis and sole findings
  authority.
- **Semantic patch:** bounded allowlisted operations against stable sections/items.
- **Provider conversation:** provider-owned opaque context used by an agent adapter.
- **Application session:** process-memory backend state and local WebSocket authorization
  boundary.
- **Reasoned no-op:** successful deep turn with zero operations and a validated reason.
- **CI-verified:** credential-free automated evidence.
- **Tenant-validated:** recent ephemeral cloud provision/smoke/destroy evidence.
- **Bring your own:** user-owned provisioning, cost, configuration, and validation.
- **Illustrative:** historical media, not continuous live evidence.
