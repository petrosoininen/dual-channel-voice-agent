# Support

This is a community reference with no production support or SLA.

- Use discussions or issues for reproducible repository defects and documentation gaps.
- Use the provider's support channel for account, billing, quota, region, outage, model,
  role, or data-processing questions.
- Use private vulnerability reporting for security issues.

Before posting, redact all real environment values, logs, provider identifiers,
endpoints, transcripts, and screenshots containing account details.
