# Security policy

## Supported versions

Security fixes are provided for the latest `0.1.x` preview/reference version only.

## Report a vulnerability

Use the repository **Security** tab and private vulnerability reporting. Do not open a
public issue for a suspected vulnerability.

Include a minimal reproduction and impact description. Do not include credentials,
tenant/subscription/principal IDs, endpoints, resource names, transcripts, customer
data, or unrelated private code. The maintainers will acknowledge and triage reports on
a best-effort basis; no response-time SLA is offered.

Provider platform incidents and account-access problems should be reported through the
provider's support channel.
